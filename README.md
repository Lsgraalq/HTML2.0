# HTML2.0 — "BIQT" landing page

> **Created: April 2022** — learning project (full multi-section landing page).

A complete single-page **creative-agency landing page** ("BIQT"), built by cutting a full design into HTML/CSS. This was a noticeable step up from earlier pages: a long, multi-section layout with consistent **BEM** class naming and hand-written CSS (no Bootstrap here).

## Sections

- **Header** — logo and top navigation (About, Service, Work, Blog, Contact).
- **Intro / hero** — headline, call-to-action button, and a side slider (Intro / Work / About / Contacts).
- **Story about us** — intro text with a three-image row.
- **Statistics** — counters (projects, clients, awards, coffee, members).
- **Services** — two rows of service cards with icons (Photography, Web Design, Creativity, SEO, Css/Html, Digital).
- **Unique design** — device mockups (tablet + phone).
- **Service / accordion** — an expandable accordion of what-we-do items.
- **Quotes** — testimonial blocks.
- **Meet our team** — team member cards with photo, name, and role.
- **Some of our work** — a masonry-style works gallery with hover captions.

## Techniques practiced

- **BEM** methodology (`block__element--modifier`) across the whole markup
- Multi-section responsive layout in plain CSS
- Google Fonts (Montserrat, Kaushan Script, Roboto)
- Reusable section patterns (`.section`, `.section--gray`, `.serv`, etc.)

## Running

Open `index.html` in a browser.
